## Промокоды

## Обобщённая схема

```text
installment_0_0_6_7_8
│           │ │ │ │ │
│           │ │ │ │ └─ Переплата клиента: 8%
│           │ │ │ └─── Потери партнёра: 7%
│           │ │ └───── Срок рассрочки: 6 месяцев
│           │ └─────── Второй базовый параметр: 0
│           └───────── Первоначальный взнос: 0
└───────────────────── Продукт «Рассрочка»
```

**Шаблон:**

```text
installment_0_0_6_7_8
```

Последний параметр необязательный. Если он отсутствует, переплата клиента в промокоде не указана.
Примечание: пример условный. Фактические условия рассрочки определяются предложением банка.
